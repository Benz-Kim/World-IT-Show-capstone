# Contributing
Use English for Markdown analysis. Keep source titles and links faithful to their originals.

For a correction, identify the claim ID, source locator, access date and reason. Distinguish vendor statements, team statements, analysis and measured results. Do not resolve a contradiction by silently choosing the more attractive number.

For results, include the protocol, operating conditions, raw-data location, failures and denominator. Do not publish personal interview details or third-party slide copies without appropriate permission.

Use one commit per coherent evidence or analysis change. Commit dates record repository work; they must not be altered to resemble historical event work. Update the README when scope or conclusions change.
