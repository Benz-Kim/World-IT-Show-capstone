# Immersive systems: when is a model a twin?
## Decision
Evaluate CODESTORY's educational and immersive work by the user task and data connection. A virtual environment is not automatically a validated digital twin.

W01 combines virtual classes, NFT galleries and digital-twin language. V02 supplies a current immersive-content portfolio, including a MetaSchool entry. These support a study of use cases, not a finding that every described real-time simulation capability was deployed in 2023.

## Distinguishing claims
| System | Minimum evidence to request | Useful evaluation |
| --- | --- | --- |
| Static virtual scene | Geometry, interaction specification | Task completion and usability |
| Connected visualization | Sensor mapping, timestamp and update path | Data freshness and missing-data behavior |
| Predictive operational twin | Calibrated model, boundary conditions, validation dataset | Prediction error on held-out operating cases |
| Educational environment | Learning objective and comparison design | Retention or transfer relative to a baseline |

These are analytical categories, not a claim about the vendor's internal architecture.

## Technical questions
A live display can be wrong because of sensor calibration, clock skew, network delay or coordinate misalignment. More realistic rendering does not remove these errors. For a predictive system, define the quantity being predicted and the operating envelope before measuring accuracy.

## Business questions
Who pays: school, exhibition operator or industrial asset owner? What requires recurring support: content revisions, device management or live data integration? These buyer and maintenance patterns differ, so a single immersive-market number would conceal rather than explain commercial potential.

## Unresolved product
The supplied EONE OMS URL was not readable during review. The smart-mirror material in W01 is therefore retained as a team presentation topic without attaching a confirmed manufacturer or repeating its disinfection claims as established facts.

## Next evidence
Request a versioned architecture diagram, demonstration data flow, consent and retention policy for user data, and a small task-based study. No user testing or learning improvement has been measured here.
